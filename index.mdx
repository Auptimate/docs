The Auptimate Client Portal is where you set up investment vehicles (also called deals), invite investors, complete identity checks, sign documents, and track the operating lifecycle of each deal. Everything happens in one secure workspace so you can move from idea to close without switching tools.

## What you can do

- **Create deals**: Set up a vehicle with the details investors need to commit.
- **Invite investors**: Send secure invites, review responses, and confirm investments.
- **Run compliance**: Collect KYC and identity verification before an investment is confirmed.
- **Sign documents**: Complete signing inline using the embedded Auptimate signing widget.
- **Operate deals**: Track ongoing activity for each vehicle after close.

<Tip>
  Sign in at [app.auptimate.com](https://app.auptimate.com) using your email. Auptimate sends a one-time code (OTP) to verify each session.
</Tip>
