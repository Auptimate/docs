The Documents area in the Auptimate Client Portal gives you a single place to manage every file attached to your deals and vehicles. You can browse by vehicle, group by document type, search by name, and filter by status and permissions so you always find what you need quickly.

## Open the Document Manager

From the main navigation, select **Documents**. The page loads your complete document library, including personal files and all documents tied to the vehicles you have access to.

## Choose how documents are grouped

Use the **Group by** toggle in the header to switch between two views:

- **Vehicles** (default): folders are organized by deal or vehicle first, then by document type inside each vehicle.
- **Document Types**: folders are organized by major type first (for example, Authority, Compliance, Accounting), then by sub-type, regardless of which vehicle they belong to.

You can switch between these views at any time without losing your place.

## Switch layout

Next to the grouping toggle, use the layout switcher to choose your preferred format:

- **Grid**: cards with file icons, names, and quick actions.
- **List**: a table with columns for file name, size, type, and selection checkboxes.

## Navigate folders

When a folder contains sub-folders, click any folder card or row to open it. A breadcrumb trail appears at the top of the page so you can jump back to any parent level, or click the root title to return to the top.

## Search and filter

To narrow the list, use the tools above the document grid or table.

### Search by name

Type into the **Quick search** field. Results update as you type and match file names and admin-given names.

### Filter by status and permissions

Click **Filter** to open the filter panel. You can combine the following criteria:

- **Status**
  - Signed/Final
  - Unsigned/Draft
- **Permissions**
  - View
  - Download
  - Sign
- **Date Range**: choose a From and To date to show only documents uploaded within that window.

Click **Apply** to confirm, **Reset** to restore the form defaults, or **Clear All** to remove every active filter.

## Understand document status

Each document shows a status indicator that tells you where it stands in the signing workflow:

- **Unsigned/Draft**: the document has not been fully signed yet.
- **Signed/Final**: the document is complete and all required signatures have been collected.

## Understand document permissions

Every document carries permission tags that control what you can do with it:

- **View**: open the file in the built-in viewer.
- **Download**: save a local copy.
- **Sign**: add your electronic signature when required.

If a permission is missing, the related action is hidden or disabled for that file.

## Select multiple documents

In list layout, use the checkbox in the table header to select all visible documents, or check individual rows. In grid layout, selection is handled per item. When at least one document or folder is selected, the **Bulk Action Bar** appears at the bottom of the screen.

From the bulk bar you can:

- See how many documents and folders are selected.
- Download all selected files you have permission for as a single ZIP archive.
- Clear the selection to start over.

Files you do not have download permission for are skipped automatically and reported in the bar.

## View a document

Click any document name or card to open it in the **Document Viewer Modal**. The viewer supports:

- PDFs rendered page by page with zoom controls.
- Images displayed inline.
- Other file types opened in a new browser tab.

While viewing, you can zoom in and out, see the total page count, and download the file if you have permission. The viewer also shows the highest permission level you hold for that document.

## See document details

Click the details action on any document row or card to open a side panel with full metadata, including description, upload date, file size, and type hierarchy.
